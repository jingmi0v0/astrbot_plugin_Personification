# ARSTBOT 拟人化插件

# 测试阶段！个人测试正常

让AstrBot机器人拥有拟人化的聊天能力，支持好感度系统、黑名单管理和QQ空间自动互动。

## 注意事项：
- 该插件还在测试阶段，如有问题请联系作者
- 作者邮箱：

- 本插件不支持在web编辑
- 需要一定的动手能力
- 请自己去文件修改配置
- （Linux目录：/root/AstrBot/data/plugins/astrbot_plugin_personification/config.yml）

- **[LivelyState](https://github.com/KonmaKanSinPack/astrbot_plugin_LivelyState)** - 角色记忆等具有长期记忆的功能
- **[智能贴表情](astrbot_plugin_emoji_like)** 任何具有修改LLM消息的插件
- **[拟人化角色系统](https://github.com/LMG-arch/astrbot-plugin-realistic-persona)** - 任何可以调用QQ空间和以及其他的插件

## 插件特色

### 🎭 拟人化聊天
- 基于LLM的自然对话生成，完全符合角色设定
- 智能上下文记忆和历史记录管理
- 支持群聊和私聊场景
- 可自定义角色性格、说话风格和行为规范
- 支持多种消息类型（文本、图片、表情等）

### 💖 好感度系统
- 动态好感度管理，范围可自定义
- 基于对话情感自动调整好感度
- 好感度过低自动拉黑机制
- 管理员可手动设置/清除好感度
- 持久化存储，重启不丢失

### 🚫 黑名单管理
- 用户和群聊双重黑名单支持
- 好感度阈值自动拉黑
- 群聊被拉黑自动退群
- 管理员可查看和管理黑名单
- 数据持久化保存

### 📱 QQ空间集成
- 自动定时发布QQ空间动态
- 基于角色设定智能生成内容
- 支持查看、点赞、评论动态
- 完全符合角色说话风格
- 可配置发帖时间和频率

### ⚙️ 高度可配置
- YAML配置文件，灵活定制
- 角色预设系统，快速切换
- 触发机制可调（@、昵称、活跃度）
- 闭嘴关键词检测
- 所有配置均为示例，无硬编码

## 主要功能

### 命令列表

#### 好感度相关
- `查看好感度 [用户ID]` - 查看指定用户的好感度信息
- `设置好感度 <用户ID> <数值>` - 设置用户好感度（仅管理员）
- `清除好感度 <用户ID>` - 重置用户好感度（仅管理员）

#### 黑名单相关
- `查看黑名单` - 查看黑名单列表（仅管理员）
- `移除黑名单 <用户ID>` - 从黑名单移除用户（仅管理员）

#### QQ空间相关
- `发说说 [内容]` - 手动发布QQ空间动态（仅管理员）
- `看说说 [数量]` - 查看最近的QQ空间动态

### 核心特性

1. **真正的拟人化**
   - AI根据角色设定实时生成回复
   - 不是简单的模板替换
   - 每个角色都有独特的说话风格

2. **智能触发机制**
   - @提及触发
   - 昵称匹配触发
   - 群聊活跃度触发
   - 私聊默认回复

3. **情感感知**
   - 基于对话内容的情感分析
   - 自动调整好感度
   - 状态持久化保存

4. **完整的QQ空间功能**
   - 集成真实QQ空间API
   - 自动生成符合角色的动态
   - 支持互动操作（点赞、评论）

5. **数据安全**
   - SQLite数据库持久化
   - 本地存储，保护隐私
   - 定期备份支持
